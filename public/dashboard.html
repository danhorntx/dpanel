      What's New in DPanel
      
        
      Version history and patch notes
      
      
      
      
    
      
    
      

      
      
      
        
      
          v2.0.0
          2026-05-11
          Major Release
        
      
        
      Major release. New security features, mail deliverability stack, in-panel database browser, Node/Python app manager, backup restore, comprehensive responsive design, and the user guide refresh.
      

        
      
          
      🆕 New Features
      
          
        
            
      • Two-Factor Authentication — TOTP-based, works with any standard authenticator (Google Authenticator, Authy, 1Password, Bitwarden)
        • 
            
      • API Keys — bearer tokens for external automation, admin + read-only scopes, audit-logged
        • 
            
      • Database Browser — phpMyAdmin-style: browse tables, view structure, run free-form SQL
        • 
            
      • Node / Python App Manager — deploy long-running services via PM2, Apache reverse proxy, live logs
        • 
            
      • Mail Health Probe — 11 deliverability checks (rDNS, HELO, MX, SPF, DKIM, DMARC, MTA-STS, TLS-RPT, TLS cert, RBL), daily cron, alerts on failure
        • 
            
      • MTA-STS & TLS-RPT — RFC 8461 / 8460 records auto-published; mta-sts.<domain> policy file + Apache vhost
        • 
            
      • DMARC Report Processor — IMAP-fetches aggregate reports, parses XML (gz/zip), stores in DB for trending
        • 
            
      • Backup Restore — restore files or databases from the UI with type-RESTORE confirmation; wipe-target + drop-recreate options
        • 
            
      • Domain Health Dashboard — per-domain aggregator: SSL, DNS, Mail Health, backups, disk, PHP, error log
        • 
            
      • Email Alerts — SSL expiry, mail-health failures, backup failures, new-admin-IP logins; deduped 24h
        • 
            
      • Audit Log UI — searchable, filterable view of every admin action
        • 
            
      • Per-domain IMAP TLS (SNI) — Dovecot serves the right cert per domain instead of one global cert
        • 
            
      • Subdomain mail support — provision app.example.com with full mail (records written into the parent zone)
        • 
            
      • File Manager — chmod editor, archive extraction (.zip/.tar.gz/etc.), bulk delete + move, image preview
        • 
            
      • Job Queue — long ops (WordPress install, future heavy ops) run async with progress polling
        • 
            
      • Mobile / Responsive — hamburger nav, table priority columns, bottom-sheet modals, touch-target sizing, mobile DB Browser layout
        • 
          
      
        
      

        
      
          
      🔧 Architecture & Reliability
      
          
        
            
      • Domain provisioning reconciler — 13 ordered steps with per-step rollback, structured step-by-step UI
        • 
            
      • Atomic create — partial failure during domain provisioning rolls back cleanly instead of leaving orphans
        • 
            
      • Apache vhost collision guard — refuses to write a vhost whose ServerName/Alias overlaps an existing one
        • 
            
      • Dynamic SERVER_IP detection — auto-detects via hostname -I, env-var override; was hardcoded to prod IP
        • 
            
      • Webmail vhost ACME exemption — Let's Encrypt renewals on webmail subdomains no longer silently fail
        • 
          
      
        
      

        
      
          
      🐛 Critical Bug Fixes
      
          
        
            
      • Empty database backups — mysqldump was being invoked with shell-substituted backticks, producing 20-byte empty .sql.gz files. Every DB backup taken since the panel was deployed was affected.
        • 
            
      • Webmail/autoconfig vhost collision — autoconfig vhost claimed webmail.<domain> as ServerAlias, intercepting webmail traffic and returning 403
        • 
            
      • Maildir creation — mkdir -p .../Maildir/{cur,new,tmp} was being created as a literal directory because dash (not bash) shell doesn't brace-expand
        • 
            
      • Missing npm dependencies — helmet, dotenv, cookie, cookie-signature, geoip-lite, isbot were used but not declared, so fresh installs crashed on boot
        • 
            
      • Admin email read from deleted config.json — Let's Encrypt registrations were using admin@<newdomain> placeholder; now reads from dpanel_users.email
        • 
            
      • Dovecot users file format — was producing entries with non-numeric UID columns that recent Dovecot versions reject
        • 
          
      
        
      

        
      
          
      🎨 UI Polish
      
          
        
            
      • Domains table redesigned: kebab menu for secondary actions, proper column alignment
        • 
            
      • All modals: full-width bottom-sheet on phones; primary action reversed to thumb-reach
        • 
            
      • Long file paths / cert subjects wrap correctly with overflow-wrap: anywhere
        • 
            
      • Touch devices: .btn-xs bumped to 32px min-height
        • 
            
      • Progressive table column hiding at 1100/900/820/700/640/560/480px breakpoints
        •
